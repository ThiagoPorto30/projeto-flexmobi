# Política de segurança

Não abra issues públicas para reportar vulnerabilidades ou exposição de dados.

Envie o relato ao responsável técnico do projeto por um canal privado, incluindo uma descrição do problema, passos para reproduzir, impacto potencial e, se possível, uma sugestão de correção. Evite compartilhar dados pessoais, tokens ou chaves no relato.

O projeto deve confirmar o recebimento, avaliar o impacto e coordenar a correção antes de qualquer divulgação pública.
