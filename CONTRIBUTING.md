# Como contribuir

## Antes de começar

1. Abra uma issue para alinhar mudanças grandes ou novos recursos.
2. Crie uma branch curta e descritiva a partir de `main`, por exemplo `feat/catalogo-filtros` ou `fix/formulario-data`.
3. Não inclua segredos, dados pessoais reais, arquivos `.env` ou conteúdo sem autorização de uso.

## Padrão de entrega

Antes de abrir um pull request, execute `pnpm typecheck` e `pnpm build`.

Descreva no pull request: o problema resolvido, como a alteração foi testada, capturas de tela em mudanças visuais e quaisquer impactos em dados comerciais.

## Commits

Prefira mensagens curtas no formato `tipo: descrição`, por exemplo `feat: adiciona filtro por autonomia`.

## Dados comerciais

Preços, disponibilidade, garantias e endereços devem ter fonte identificável e validação do responsável comercial antes de serem publicados.
